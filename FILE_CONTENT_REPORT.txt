EVOLVE STAFF — SOURCE AND CONFIGURATION FILE CONTENT REPORT
Repository: meriem-dev-esi/evolve_staff
Application: Flutter staff/admin dashboard

Scope
This report summarizes source and configuration file purpose; it does not copy
the source code itself. Generated build/.dart_tool output and local secrets are
excluded. Binary icons are described by role. Descriptions reflect the files
currently present, including the local untracked admin-feature files. The
dependency lockfile is identified but not expanded line by line.

FLUTTER APPLICATION AND SCREENS
lib/main.dart — Initializes Flutter and Supabase and starts the Evolve Staff app at login.
lib/screens/assignments_screen.dart — Lists/filters course assignments, creates assignments, and supports submission review and grading.
lib/screens/course_details_screen.dart — Shows course details and lessons, with links to editing, lesson management, and course files.
lib/screens/course_files_screen.dart — Lists course file records and uploads files to Supabase Storage with saved metadata.
lib/screens/courses_screen.dart — Lists, searches, and filters courses; includes course editing and administrator moderation actions.
lib/screens/create_course_screen.dart — Course creation form for description, pricing, category, and publication fields.
lib/screens/dashboard_screen.dart — Role-aware staff navigation/dashboard with statistics, activity, shortcuts, and sign-out.
lib/screens/edit_course_screen.dart — Edits course details, pricing, and publication fields and saves to Supabase.
lib/screens/formations_screen.dart — Lists formations/series, creates them, and shows associated courses.
lib/screens/lesson_details_screen.dart — Displays lesson title, order, description, and edit navigation.
lib/screens/lessons_screen.dart — Lists lessons with course context and provides course/search filters and lesson creation.
lib/screens/login_screen.dart — Validates credentials, signs in with Supabase Auth, checks staff role, and routes authorized users.
lib/screens/messages_screen.dart — Displays student conversations with search/unread filters and refresh on real-time message events.
lib/screens/revenue_screen.dart — Displays recorded revenue, refunds, expenses, enrollment counts, and course totals with refresh/error states.
lib/screens/student_progress_screen.dart — Shows student course-completion summaries with search, refresh, and per-student detail.
lib/screens/users_management_screen.dart — Lists and filters profiles and supports administrator user management and invitations.
